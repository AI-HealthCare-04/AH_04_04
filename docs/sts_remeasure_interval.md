# 5STS 권장 재측정 주기 = 3개월 — 근거와 결정 (#353)

기록 탭 5STS 카드가 안내하는 재측정 주기를 **3개월**로 정한 근거를 남긴다.
문구를 바꾸거나 주기를 조정할 때 이 문서를 먼저 확인할 것.

- 적용 위치: `record/StsTrend.kt` 의 `STS_REMEASURE_INTERVAL_NOTICE`
- 결정일: 2026-08-01 (PR #355 리뷰에서 임상 판단 확인 항목으로 제기됨)

## 결론

> "3개월에 한 번 정도 다시 재보시면 변화를 확인할 수 있어요."

4주(한 달) 안내를 3개월로 바꿨다. **측정 오차를 넘는 변화가 나오기 전에 다시 재게 하면,
성실히 운동한 사용자에게도 '지난번과 비슷해요'만 반복 표시되어 동기를 꺾기 때문**이다.

## 근거

### 1. 낙상 예방 운동의 권고 기간 — 최소 12주 (직접 근거)

World Falls Guidelines WG4 권고(**등급 1A**, 강한 권고·높은 근거 수준):

> balance challenging and functional exercises (e.g. **sit-to-stand**, stepping), with sessions
> three times or more weekly which are individualised, progressed in intensity **for at least 12 weeks**

- 5STS 동작(sit-to-stand)이 권고 운동에 직접 포함된다.
- 더 큰 효과를 위해 12주보다 오래 지속할 것을 권고한다.
- → **운동 효과를 확인하는 시점으로 3개월은 가이드라인 권고 기간과 일치한다.**

### 2. 최소감지변화(MDC) — 약 3초 (변화 판정의 하한)

| 대상 | MDC | 재검사 간격 |
|---|---|---|
| 지역사회 거주 낙상 고위험 노인(평균 73.7세, n=30) | **3.50초**(약 25%) | 1주 |
| 장기요양 사르코페니아 노인(평균 79.9세, n=38) | 전체 2.87초 / 사르코페니아군 3.12초 | 1-7일 |

- 재측정에서 **약 3초 이상** 차이가 나야 측정 오차가 아닌 실제 변화로 볼 수 있다.
- 카드의 '지난번보다 N초 빨라졌어요' 문구가 의미를 가지려면 이 크기의 변화가 필요하다.
  (앱의 0.1초 미만 '비슷해요' 임계는 표시 안정성용이지 임상 판정 기준이 아니다.)

### 3. 저항운동 중재 기간 중앙값 12주 (간접 근거)

저항운동 메타분석(17편): 중재 기간 6주-12개월, **중앙값 12주**, 기능적 결과 효과크기 0.72
(95% CI 0.39-1.07). 12주 기능적 저항운동 RCT 에서 5STS **-2.3초** 개선(대조군 대비).

⚠️ 이는 **연구 설계상의 기간이지 공식 재측정 권고 주기가 아니다.** 3개월 안내를 뒷받침하는
간접 근거로만 쓴다. 재측정 주기 자체를 규정한 공식 권고는 확인되지 않았다(아래 참고).

### 4. 가이드라인에 재평가 주기 규정은 없음

- AWGS 2019 / 2025 는 진단 알고리즘과 컷오프(5STS ≥12초 = 저수행)를 정할 뿐 **재평가 주기는 명시하지 않는다.**
- 별도 건강경제 연구에서 지역사회 **연 1회** 사르코페니아 스크리닝이 비용효과적이라는 평가가 있다
  (스크리닝 주기이지 개인의 운동 효과 확인 주기는 아님).
- → 3개월은 '공식 재측정 권고'가 아니라 **운동 효과 확인 시점으로서의 합리적 안내**로 표현한다.

## 비의료 포지셔닝 유지 (#57)

- 12초 컷오프(AWGS 저수행 기준)는 화면에 기준선으로 표시하지 않는다 — 판정으로 읽힐 수 있다.
- 카드 문구는 '빨라졌어요 / 느려졌어요 / 비슷해요'(사실)까지만. 저하·위험 등 판정 표현 금지.
- 이 문서의 임상 수치는 **주기 결정의 내부 근거**이며 사용자 화면에 노출하지 않는다.
