# 아이고(AIGO) 평가용 APK 실행 가이드

> 캠프 평가자님께 — 설치부터 체험까지 이 문서 하나로 진행하실 수 있습니다.
> 별도 회원가입·소셜 로그인 없이 **"체험으로 시작하기"(익명 게스트)** 기준으로 안내합니다.
> 입력하시는 값은 체험용 계정에만 연결되니, **실제 개인정보 대신 이 문서가 안내하는
> 가상 값을 입력해 주세요.**

## 1. 설치

- 요구 사항: **Android 7.0 이상** 휴대폰, 인터넷 연결(Wi-Fi 또는 LTE)
- 전달받은 APK 파일을 휴대폰에서 열어 설치합니다.
  - "출처를 알 수 없는 앱" 경고가 뜨면: 안내에 따라 **이 출처 허용 → 설치**를 누릅니다.
    (평가용 직접 배포 파일이라 스토어 외 설치 확인이 뜨는 것으로, 정상입니다.)
- 설치 후 홈 화면의 **아이고** 아이콘을 눌러 실행합니다.

## 2. 시작하기 — 체험으로 시작하기

1. 시작 화면에서 **"체험으로 시작하기"** 를 누릅니다. (Google·카카오 로그인은 실사용자용 —
   평가에는 필요하지 않습니다)
2. 약관 동의 화면: 각 항목 오른쪽 **"보기"** 로 전문을 확인할 수 있습니다. 필수 항목 동의 후 계속.
3. 건강 프로필 입력 — ⚠️ **생년월일은 만 65세 이상으로 입력하시기를 권장합니다 (예: 1955년 1월 1일).**
   - 아이고의 근육 건강 점수·예측은 현재 65세 이상 기준으로 제공됩니다. 65세 미만으로
     입력해도 체험은 가능하지만 점수 화면이 "준비 중"으로 표시되어 전체 기능을 보실 수
     없습니다 — 시니어 페르소나로 체험해 주시기를 부탁드립니다.
   - 실제 개인정보를 넣으실 필요가 없습니다 — 생년월일·키·몸무게 모두 가상 값
     (예: 1955년 1월 1일 / 165cm / 60kg)이면 됩니다.
4. 활동 입력: 일주일에 며칠 걷기·근력 운동을 하는지 선택(0일도 선택 가능).
5. 간단 체력검사(의자에서 일어나기)는 **"건너뛰기" 하셔도 됩니다.** 완료하면 홈 화면으로 이동합니다.

## 3. 추천 체험 코스 (10-15분)

| 순서 | 화면 | 해보실 것 |
|---|---|---|
| 1 | **홈** | 오늘의 미션 요약과 펫, 미션별 진행 상황 |
| 2 | **미션 탭 → 운동** | 안전 안내 확인 → 운동 그림(포스터)을 눌러 전체화면 영상 재생 → 닫은 뒤 다시 열면 보던 위치에서 이어보기, 화면의 "오늘 누적 운동시간" 확인 |
| 3 | **미션 탭 → 식사** | 단백질 식품 1가지 이상 선택 → 저장 → 목표 달성·포인트 적립 확인 (같은 날 다시 저장해도 중복 적립되지 않습니다) |
| 4 | **미션 탭 → 게임** | 인지 게임 영상 시청 |
| 5 | **기록 탭 → 근육 건강 정보** | **근육 건강 점수**(또래 비교 긍정 점수)·구간 배지·"이렇게 하면 이만큼" 시뮬레이션 |
| 6 | **기록 탭 → 나의 기록** | 방금 완료한 미션이 그래프·달력에 반영된 것 확인 |
| 7 | **설정** | 글자 크기·소리 크기(시니어 접근성), 내 정보 수정 |

- **걷기 미션**은 실제 보행(가속도 센서)으로 판정되어 앉은 자리 체험이 어렵습니다 —
  시작해 보시면 측정 화면·상단바 알림("걷기 측정 중")까지 확인하실 수 있습니다.

## 4. 알아두실 점

- **대부분의 기능은 인터넷 연결이 필요합니다.** 연결이 끊기면 "연결을 확인해 주세요"
  안내가 뜨며, 재연결 후 "다시 시도"로 복구됩니다(의도된 동작).
  - 예외: **진행 중인 걷기 측정은 인터넷이 끊겨도 계속됩니다** — 완료 저장이 실패하면
    재연결 후 다시 시도하도록 설계되어 있습니다.
- **게임 완료 포인트는 다음 버전에서 적립됩니다** — 현재 버전은 영상 시청까지 제공합니다.
- **처음부터 다시 체험하려면**: 휴대폰 설정 → 애플리케이션 → 아이고 → 저장공간 →
  **데이터 삭제** 후 앱을 다시 실행하면 새 체험 계정으로 시작됩니다.
  (앱 안에서 로그아웃하면 간편로그인 화면으로 이동합니다 — 체험을 다시 하시려면 위 방법을 이용해 주세요.)
- 점수·기록은 참고용이며 의학적 진단이 아닙니다(앱 내 고지 동일).

## 5. 문제가 있을 때

- 화면이 멈추거나 일시적인 오류가 보이면: 먼저 화면의 **"다시 시도"** 를 눌러 주세요.
- 그래도 안 되면 앱을 완전히 종료 후 다시 실행할 수 있습니다 — 다만 **체험(게스트) 계정은
  앱을 완전히 종료하면 이전 세션으로 돌아가지 않고, 재실행 시 새 체험을 처음부터 시작**하게
  됩니다(체험 계정을 기기에 남기지 않는 동작). 평가 중에는 가급적 "다시 시도"를 이용해 주세요.
- 서버 점검 등으로 접속이 안 될 경우를 대비해 평가 기간 동안 서버를 상시 운영 상태로 유지합니다.
  이상이 지속되면 제출물에 기재된 팀 연락처로 알려주시면 즉시 확인하겠습니다.
