# 모델 탐색·의사결정 이력 (심사 3-1 근거)

근감소증 예측 모델을 확정하기까지 수행한 실험과 그 결과·결정·근거를 정리한다. 각 항목은 **시도 → 측정값(± 95% CI) → 결정 → 이유** 구조이며, 버린 대안(negative result)도 함께 남긴다. 확정 성능과 days/binary·LR/트리·표집가중 평가·5fold/8020 비교는 `scripts/ml/evaluate_model.py`로 재현되고 `metrics.json`에 저장돼 있다(random_state=42). 그 밖의 라벨·변수·음주·흡연·클래스가중·IPW 탐색 수치는 모델 담당자 작업공간 기록으로, 커밋된 스크립트의 재현 범위에는 포함되지 않는다.

**공통 조건**: KNHANES 2022–2024, 65세 이상, AWGS 2025 라벨(저근육량 AND 저악력), 유효표본 **n=4,279**, 유병률 **13.27%**. 검증은 StratifiedKFold(5, shuffle, seed=42) OOF. ECE는 10 bins. **AUPRC 기준선(무작위)=유병률 0.1327**이므로 AUPRC는 항상 이 값과 비교해 읽는다.

## I. 라벨·모델 탐색

### 요약 표

| 시도 | 측정값 | 결정 | 이유 |
|---|---|---|---|
| 라벨 AWGS 2019 → 2025 | 비만(BMI≥25) 양성 검출 2.5%→10.1%; 유병률 9.84%→13.27% | **2025 채택** | 근거는 성능 아닌 **커버리지**(근감소성 비만 포착) |
| 변수 최소화 | 5→7→9→17변수 AUROC 0.830→0.835→0.838→0.837 | **7변수(기본형)** | 앱 수집 가능 + 성능 포화 |
| 허리둘레 | ΔAUPRC **+0.0225** [+0.0067, +0.0374] (탐색적 작업공간 기록); 예측대치는 제외모델 못 넘음 | **2-모델(유무 분기)** | 성능 향상이 관측됐으나 미입력자 대치는 무효 |
| 걷기/근력 인코딩 | days AUROC 0.8227 vs binary 0.8220 (동일) | **일수 기반 채택** | 성능 동일한데 **what-if 시뮬레이션** 가능 |
| 음주 추가 | AUPRC 0.4601 → 0.4590~0.4613 (무변화) | **제외** | 이득 없음, 복잡도만↑ |
| 흡연 추가 | AUPRC 0.4601 → 0.4580~0.4598 (오히려↓) | **제외** | 이득 없음 |
| LR vs 트리 | AUROC 0.8227 vs 0.786; AUPRC 0.4361 vs 0.377 | **로지스틱** | 상호작용 불필요, 보정·해석 우수 |
| 체격대비형(근감소성 비만) | 음성 대비 AUROC 0.736, 개선 시도 전부 실패 | **한계 인정** | 기능검사 부재 → 5STS 오버레이로 보완 |

### 상세

**1) 라벨 정의 2019 → 2025.** AWGS 2019(키보정 ASMI + 악력)는 근육량을 키²로만 보정해 체중이 큰 사람의 근감소성 비만을 구조적으로 놓친다(BMI≥30 유병률 2019 0.6% vs 2025 9.3%). AWGS 2025는 BMI 보정 지표(ASM/BMI)를 공식 결합(ASMI **또는** ASM/BMI)해 이 사각지대를 잡는다. 비만군(BMI≥25) 양성 검출이 39/1,539(2.5%)→155/1,539(10.1%)로 4배. **전환 근거는 모델 성능이 아니라 커버리지**다(두 라벨은 정답이 달라 AUROC 직접 비교가 무의미). 유병률 9.84%→13.27%로 AUPRC 기준선도 상승.

**2) 변수 최소화.** 앱에서 실제 받을 수 있는 최소 입력을 찾기 위해 5/7/9/17변수를 비교. AUROC 0.830→0.835→0.838→0.837로 7변수 이후 **성능이 포화**됐다. 혈압·혈액검사(9·17변수)의 추가 이득이 미미하고 앱 온보딩 부담만 커져, **나이·성별·키·체중·BMI·걷기·근력의 7변수(기본형)**로 확정.

**3) 허리둘레.** 실제 허리 입력 모델의 성능이 더 높게 관측됐다(ΔAUPRC **+0.0225**, 95% CI [+0.0067, +0.0374]). 이 차이와 CI는 모델 담당자 작업공간의 탐색 기록이며 커밋된 스크립트로 재산출되지 않는다. 두 모델의 유효 표본도 4,279명과 4,266명으로 달라 엄밀한 짝지어진 비교가 아니므로, 확정 성능 표의 모델별 지표를 우선해 해석한다. 미입력자에게 BMI로 예측한 허리를 대치하면 허리 없는 모델을 넘지 못해 **입력자=허리 포함 / 미입력자=허리 제외의 2-모델 정책**으로 확정했다.

**4) 걷기·근력 인코딩(일수 vs 이분형).** 기존 이분형(주5일·주2회 y/n)을 일수(걷기 0–7, 근력 0–5)로 바꿔 재평가한 결과 성능은 동일(AUROC 0.8227 vs 0.8220, AUPRC 0.4361 vs 0.4368). **성능이 같은데도 일수를 택한 이유는 "근력을 하루 늘리면 위험이 얼마나 주는가"의 what-if 시뮬레이션·챌린지 UX가 가능**해지기 때문이다. 성능 유지 + 제품 가치 추가의 품질 개선 사례.

**5) 음주·흡연(추가 후 기각).** 생활습관 변수를 넣어봤으나, 음주는 AUPRC 0.4601→0.4590~0.4613(무변화), 흡연은 0.4601→0.4580~0.4598(오히려 하락). **이득이 없어 모델 복잡도를 늘리지 않고 제외**했다(과적합 회피). "테스트했고 도움이 안 돼 넣지 않았다"는 판단의 근거로 지표를 보존.

**6) LR vs 트리.** HistGradientBoosting 대비 로지스틱이 우수(AUROC 0.8227 vs 0.786, AUPRC 0.4361 vs 0.377). 비선형·상호작용이 성능을 좌우하지 않으며, 로지스틱이 **보정(ECE 0.0053 vs 0.0513)과 해석**에서 앞서 최종 채택. (2-1 기술 스택 근거로 재사용.)

**7) 체격대비형 실패 → 기능검사 필요.** 근감소성 비만(무거운데 저근육) 판별은 체형 변수만으로 어렵다(음성 대비 AUROC 0.736). 추가 체형·대사 변수, 비만 전용 모델 등 개선 시도가 모두 실패(≤+0.01). 근본 원인은 **근육·근력 기능 신호가 입력에 없기 때문**이며, KNHANES엔 5STS·보행속도가 없어 앱 자체 수집이 필요. → 규칙 기반 5STS 오버레이(가이드라인 근거 안전망)로 보완하기로 결정.

## II. 검증 방법

### 요약 표

| 시도 | 측정값 | 결정 | 이유 |
|---|---|---|---|
| 5-fold CV vs 80/20 holdout | AUROC 0.8227 vs 0.8085 (AUPRC 0.436 vs 0.407) | **5-fold OOF** | 단일 분할보다 안정적(작은 n·불균형) |
| 비가중 OOF 예측의 비가중 vs 표집가중 평가(wt_hs) | AUROC 0.8227 vs 0.8162, ECE 0.0053 vs 0.0092 | **비가중 평가** | 차이 미미, 관측 유병률 보정 유지 |
| 비가중 vs 클래스가중(balanced) | ECE 0.0053 vs **0.238**, 평균확률 13%→37% | **비가중** | 클래스가중은 **보정 붕괴** |
| 선택편향(IPW) 보정 | AUPRC 변화 **+0.29%p** | **미적용(진단용만)** | 효과 미미 |

### 상세

**8) 지표 선택 근거(AUPRC·Brier·ECE).** 유병률 13.27% 불균형이라 AUROC는 낙관적으로 보인다. 그래서 **AUPRC를 기준선(0.1327) 대비**로 읽는다 — 예: minimal 0.436 = 기준선의 **3.3배**. 또한 **사용자에게 보이는 점수·백분위·what-if가 모두 예측확률의 결정적 변환**이므로, 순위 품질(AUROC)보다 **보정(Brier·ECE)**이 실제 화면 값을 좌우한다. 최종 모델의 ECE는 minimal 0.0053 / with_waist 0.0134로, "40%"라고 나오면 실제 위험도 약 40%에 해당할 만큼 보정이 양호. (ECE는 10 bins.)

**9) 5-fold vs 80/20.** 두 방식 결과가 일치(AUROC 0.8227 vs 0.8085). 단일 80/20 holdout은 작은 표본·불균형에서 분할 운에 따른 분산이 커, **5-fold OOF**를 주 검증으로 채택. fold별 AUROC는 minimal 0.823±0.008, with_waist 0.836±0.004로 안정적.

**10) 표집가중 평가.** 모델을 표집가중으로 다시 학습한 비교가 아니다. 동일한 비가중 모델의 OOF 예측에 KNHANES 건강설문 가중(wt_hs, 평균 1 정규화)을 적용해 **평가 지표만 재산출**했으며, 결론은 불변이었다(AUROC 0.8227→0.8162, AUPRC 0.436→0.411, ECE 0.0053→0.0092). 앱 모집단이 국건영 모집단과 다르고 비가중 평가가 관측 유병률에 맞으므로 이를 주 결과로 채택했다. 별도 작업공간에서 수행한 클래스가중 학습(balanced)은 오히려 **보정을 붕괴**시켜(ECE 0.0053→0.238, 평균확률 37%) 확률을 그대로 쓰는 이 서비스에 부적합했다.

**11) 선택편향(IPW).** 표본이 "악력+BIA를 모두 측정한 사람"으로 한정된 선택편향을 IPW로 점검. 보정 효과가 +0.29%p로 미미해 **최종 모델엔 미적용**(진단 목적 참고만). 한계로 문서에 명시.

## III. 점수·범위 설계 탐색

(모델 성능이 아니라 사용자 노출 점수·대상 범위 설계에 대한 실험. 세부는 ADR·점수설계 보고서 참조.)

### 요약 표

| 시도 | 측정값 | 결정 | 이유 |
|---|---|---|---|
| ±3 단일나이 vs 5세 밴드 | 밴드는 경계(74→75)에서 점수 **+26~33점 점프** | **±3 이동창** | 경계 자체 제거(매끄러움) |
| 50대 조기컷 vs 65 표준컷(점수) | Spearman **0.97**, 컷 재조정 시 밴드 **90% 일치**, 좋음↔주의 뒤집힘 0% | v1 **65 표준컷** | 점수는 사실상 호환, 방어력(표준 컷)만 차이 |
| 80세 이상 처리 | 원자료 top-coding → 창 왜곡 | **80+ 별도 풀** | 나이 분해 불가 |
| 곡선 다듬기(LMS/LOWESS) | 두 방법 차이 미미(중앙값 일치) | **폐기** | 80 제외 시 이미 단조, 불필요 |

### 상세

**12) ±3 단일나이 이동창.** 5세 밴드는 경계에서 점수가 튄다(74→75세에 +26~33점). ±3세(폭 7년) 단일나이 이동창은 나이를 따라 미끄러져 경계 자체를 없앤다. 상단은 80세 top-coding 때문에 폭7 고정(77–79 수렴), 80+는 별도. 온보딩 추정값(키/몸무게)도 같은 ±3로 통일해 정합.

**13) 50대 조기컷 vs 65 표준컷.** 50–64를 v1에 포함할지 검토하며 두 모델(중년 단일컷 B모델 / 65+ 표준컷 임상모델)의 점수를 65+ 3,357명에게 비교. **Spearman 0.97**, 컷 재조정 후 밴드 90% 일치, 극단 오분류(좋음↔주의) 0%. 즉 상대점수는 사실상 호환. 그럼에도 v1을 65 표준컷으로 둔 이유는 점수가 아니라 **온보딩 위험 카드의 임상 방어력(연령 표준 컷)** 때문. 50–64는 post-v1 에픽으로 보류(모델·패키지 보관).

**14) 곡선 다듬기 폐기.** LMS vs LOWESS 비교 결과 차이가 미미했고(중앙값 완전 일치), 80세 이상을 별도 풀로 빼자 원 곡선이 이미 단조로워 **다듬기 자체가 불필요**해져 폐기. 불필요한 복잡도 제거.

## 한계 (Interpretation limits — 삭제 금지)

- 내부 검증(단일 데이터셋 OOF)이며 외부 코호트 검증은 미수행.
- 표본이 "악력+BIA 측정자"로 한정된 선택편향(IPW 점검: 효과 +0.29%p로 미미).
- 표집가중 미적용(데모 조건). 앱 모집단이 국건영과 다를 수 있음.
- 근감소성 비만 판별력 한계(체격대비형 AUROC 0.736) → 5STS 오버레이로 보완하되, 이 오버레이는 국건영에 5STS가 없어 우리 데이터로 검증 불가한 **가이드라인 근거 안전망**이다.
