# 온보딩 기본 신체계측 추정값

키·몸무게를 **모름**으로 선택한 사용자에게 적용하는 기본값의 정본과 산출 기준을 보존합니다.

## 정본

- `default_anthropometry_5079_pm3.json`: 남녀 50~79세 단일나이별 값과 80세 이상 별도 값
- Android 구현: `android/app/src/main/java/com/aihealthcare/ah0404/onboarding/DefaultAnthropometry.kt`

구형 50~64세 밴드형 산출물(`default_anthropometry_5064*`)은 단일나이 정본으로 대체되어 사용하지 않습니다.

## 데이터와 방법

- 출처: 국민건강영양조사(KNHANES) 2022·2023·2024 원시자료의 전체 조사 파일
- 변수: 성별(`sex`), 나이(`age`), 신장(`HE_ht`), 체중(`HE_wt`)
- 표본: 각 창에서 신장과 체중이 모두 유효한 응답자 전원
- 통계: 미가중 중앙값
- 연령 창: 성별 × 단일나이 ±3세, 폭 7년
- 50~79세 상단 처리: `hi=min(age+3,79)`, `lo=hi-6`
- 80세 이상: 원자료의 나이 top-coding 때문에 별도 풀로 집계

65세 경계에서도 신장·체중의 정의는 바뀌지 않으므로 창을 끊지 않습니다. 따라서 65세는 62~68세 창을 사용하며 50~79세가 하나의 연속된 곡선을 이룹니다.

## 적용 범위

- 키·몸무게 모름: 만 50세 이상에서 성별과 만 나이에 해당하는 값을 사용
- 50세 미만: 추정 근거가 준비되지 않아 지원 연령 사유와 함께 직접 입력을 안내
- 80세 이상: 80세 이상 풀의 값을 사용
- BMI: 저장된 키·몸무게로 계산하므로 별도 기본값을 두지 않음
- 허리둘레 모름: 기본값을 채우지 않고 허리 없는 모델 정책을 사용

원시 KNHANES 자료는 용량과 배포 조건 때문에 저장소에 포함하지 않습니다. 이 디렉터리의 JSON은 앱 상수표와 독립 대조할 수 있는 감사용 정본 스냅샷입니다.
