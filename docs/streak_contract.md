# 스트릭 권위 계약 (#146 1단계)

## 목적

홈의 펫 칭찬 문구가 사용할 연속 달성일을 서버가 일관되게 계산한다.
Android는 스트릭을 자체 계산하거나 저장하지 않고 `GET /api/v1/home`의 값을 그대로 사용한다.

## 달성일과 날짜 기준

- 달성일은 `daily_activity_summaries.counted_mission_count > 0`인 날짜다.
- 같은 날 성공한 미션이 여러 개여도 스트릭은 하루만 증가한다.
- 실패, 중단, 목표 미달, 일일 한도를 초과한 중복 완료는 새 달성일을 만들지 않는다.
- 날짜 경계는 서버의 KST(`Asia/Seoul`, UTC+09:00) 기준이다.
- 기기 날짜나 기기 타임존은 스트릭 계산에 사용하지 않는다.

## 현재 스트릭

- 오늘이 달성일이면 오늘부터 과거로 연속된 달성일 수를 반환한다.
- 오늘이 아직 달성일이 아니면 어제부터 과거로 연속된 달성일 수를 반환한다.
- 가장 최근 달성일이 그제 이전이면 현재 스트릭은 0이다.
- 오늘 미완료라는 이유만으로 어제까지의 스트릭을 자정 전에 끊지 않는다.
- 끊긴 뒤 다시 달성하면 1일부터 시작한다.

## API

`GET /api/v1/home` 응답에 다음 필드를 추가한다.

```json
{
  "streak": {
    "current_days": 3,
    "completed_today": true,
    "as_of_date": "2026-07-27"
  }
}
```

- `current_days`: 서버가 계산한 현재 연속 달성일
- `completed_today`: 서버 기준 오늘 달성 여부
- `as_of_date`: 계산에 사용한 KST 날짜

기존 홈 응답에 필드를 추가해 스트릭만을 위한 별도 네트워크 요청은 만들지 않는다.
최장 스트릭, 보상, 랭킹, 배지와 푸시 알림은 이 계약의 범위가 아니다.

## Android 후속 계약

- 앱은 `current_days`를 자체 계산하거나 낙관적으로 증가시키지 않는다.
- 조회 실패, 인증되지 않은 사용자 또는 스트릭 0일에는 기존 일반 말풍선을 사용한다.
- 스트릭 중단을 질책하거나 불안을 유발하는 문구는 사용하지 않는다.
- 같은 칭찬의 중복 방지는 `streak:{as_of_date}:{current_days}` 형태의 안정적인 키로
  기존 펫 말풍선 중복 방지 정책(#145)에 연결한다.

## 오프라인 후속

이슈 #105의 outbox가 구현되기 전에는 오프라인 완료를 앱이 스트릭에 선반영하지 않는다.
재연결 후 서버가 완료 이벤트를 수락하고 홈을 다시 조회했을 때 권위값으로 갱신한다.
