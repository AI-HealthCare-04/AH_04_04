### 멘트 포인트
- 점수 화면: "확률이나 위험 퍼센트가 아니라 **또래와 비교한 긍정 점수**로 보여드립니다 — 시니어 불안을 만들지 않기 위한 설계입니다."
- 안전 고지: "운동 시작 전 안전 확인을 서버가 강제합니다 — 확인 없이 시작하면 서버가 거부해요."
- 걷기는 실시간 시연이 어려우므로(실보행 필요) **화면 설명 + 기록 탭의 걷기 그래프**로 대체.

## 2. 트랙 B — 심사위원 체험 안내

**안내 멘트(제안)**: "별도 회원가입이나 소셜 로그인 없이 익명 게스트로 체험하실 수 있습니다.
입력하시는 값은 체험용 계정에만 연결되니, 실제 개인정보 대신 안내드리는 가상 시니어
페르소나 값을 입력해 주세요."

> ℹ️ 표현 주의(리뷰 #316): 게스트도 입력한 생년월일·신체·건강정보가 서버에 **저장**된다.
> "개인정보 미수집"을 절대적으로 단정하지 말 것 — **가상 값 입력 안내**로 같은 의도(평가자
> 실개인정보 비수집)를 전달한다.

### ⚠️ 반드시 안내에 포함할 것 — 두 개의 포인트

1. **생년월일은 만 65세 이상(가상 값) 권장**: 최종 RC(#313) 기준으로 65세 미만도 온보딩을
   완료할 수 있으나, 근육 건강 점수 등 예측 기능이 "준비 중"으로 표시된다(v1 모델이 65세
   이상 전용). **전체 기능을 체험하려면 65세 이상 가상 생년월일(예: 1955년) 입력을 권장.**
   → 멘트: "시니어 페르소나로 체험하시도록 생년월일은 65세 이상(예: 1955년)으로 입력해
   주세요 — 실제 생년월일을 넣으실 필요는 없습니다." 
2. **체험 → 로그아웃 → 재체험은 안 됨**: 로그아웃하면 재로그인 게이트(소셜만)로 가고
   체험하기 버튼이 없다. 심사 기기는 **신규 설치 상태로 준비**하고, 체험을 다시 시작하려면
   앱 데이터 삭제(설정 → 앱 → 저장공간)로 초기화.

### 심사 기기 준비
- 제출 APK를 새로 설치한 상태(=시작 화면에 체험하기 노출)로 준비
- 심사위원이 여러 명이면: 체험 사이마다 앱 데이터 삭제(1분) — 담당 1인 지정

## 3. 촬영 구성 원칙 (팀 결정 2026-07-31: 에러도 투명하게 보여준다)

**시연 영상은 정상 흐름 + 알려진 에러·제한 장면을 의도적으로 포함**해 촬영한다 — 숨기지 않고
"저희는 이 제한을 알고 있고 이렇게 안내합니다"로 프레이밍(심사 신뢰도 관점 유리).

포함 후보 장면(안내 화면이 정상 노출되는 것들):
- 오프라인 전환 → 연결 안내 + 재시도 → 재연결 복구 — 회복력 장면으로만 프레이밍
  ("완전 오프라인 지원"으로 과장 금지, 리뷰 #316)
- (오류 아님 — 정책 설명) 65세 미만 입력 시 예측 "준비 중" 안내(#313) — 대상 범위와
  확장 로드맵을 설명하는 정책 장면
- 게임 완료 후 포인트 미적립 → 로드맵 멘트

> 리뷰 권고(#316, 비차단 — 팀 결정 사항): 본편 7-8분은 **정상 핵심 가치 중심**으로.
> 게임 미적립은 본편 재현 대신 제출 README/로드맵 명시가 낫다는 의견. 권장 본편 순서:
> 문제·대상 20초 → 홈 → 운동 안전/이어보기 → 식사 중복방지 → 기록 점수·시뮬레이션 →
> 내정보 재평가 → 마무리. 약관 보기·오프라인 복구는 짧은 선택 컷.

### 여전히 피할 것
- ❌ 게임 완료 후 "포인트가 쌓였다"고 말하는 것 — 미적립을 숨기지 말고 위처럼 로드맵으로 안내
- ❌ 시연 중 로그아웃 — 체험하기로 못 돌아감(위 함정 2)
- ❌ 발표 직전 앱 업데이트·서버 배포 — RC2 동결 이후 머지 금지

## 4. 영상 용도 (확정: 캠프 평가 제출 전용)

발표(ZEP)에서는 영상을 재생하지 않는다 — 촬영한 시연 영상(#305)은 **캠프 평가용 제출물**로만
쓴다. 트랙 A(1절)는 이 **제출 영상의 촬영 각본**, 트랙 B(2절)는 평가자가 제출 APK로 직접
체험할 때의 안내 — **심사위원 체험 안내문으로 제출물에 동봉 권장**.

### 대비할 것

| 상황 | 대응 |
|---|---|
| 제출 전 영상 파일 유실 | 파일 **이중 보관**: 촬영자 로컬 + 클라우드 + 팀 드라이브 |
| 평가 기간 서버 장애 | 평가 기간 **배포 동결 유지** + /health 주기 확인(담당: 란) — 평가자 APK 체험이 서버 의존 |
| 촬영 중 앱/계정 이상 | 예비 게스트 즉석 생성(체험하기) / 제출 APK 사본으로 재설치 |
