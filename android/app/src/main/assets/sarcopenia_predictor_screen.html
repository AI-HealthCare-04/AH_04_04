해석 주의

• 근력운동은 하루씩 늘 때 위험이 뚜렷이 낮아지지만, 걷기는 완만합니다. 이는 표시 문제가 아니라 데이터에서 걷기의 신호가 약한 실제 경향입니다(관찰 데이터 기반이라 인과 아님).
• 근감소증이 근육량 기준이라 무거울수록 낮게 나옵니다. 근육 적고 지방 많은 근감소성 비만은 낮게 표시돼도 실제 고위험일 수 있어 기능검사가 필요합니다.
• 65세 미만·학습범위 밖 입력은 참고용이며 경고가 표시됩니다.
